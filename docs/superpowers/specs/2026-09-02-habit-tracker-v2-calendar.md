# Трекер привычек v2 — модель iOS-календаря

Дата: 2026-09-02
Статус: утверждено, готово к планированию реализации
Заменяет визуальный слой из [2026-09-02-habit-tracker-design.md](2026-09-02-habit-tracker-design.md).

## 1. Обзор

v1 показывал привычки как GitHub-хитмап с переключателем диапазона. v2 переходит
на модель нативного iOS-календаря: по каждой привычке — свой календарь с тремя
уровнями масштаба (3 месяца → месяц → год). Отметка дня = день закрашивается
цветом привычки. Метрики (стрик, всего дней, % за период) убираются полностью.

Неизменно: статическое веб-приложение, публикуется на GitHub Pages, ставится на
домашний экран как PWA, работает офлайн, данные только в `localStorage`, один
пользователь, без бэкенда. Светлая и тёмная тема (по системе + ручной выбор).

### Что меняется по пунктам (запрос пользователя)
1. Нет горизонтального скролла нигде; контент строго по ширине экрана.
2. Главный экран: по каждой привычке 3 месяца (предыдущий / текущий / следующий),
   стиль базового iOS-календаря, текущий день — красная цифра.
3. Тап по месяцу → экран месяца этой привычки; тап по дню отмечает его цветом
   привычки (кружок).
4. «Отдаление» до года: все 12 месяцев года с отметками, только вертикальный
   скролл, можно листать в прошлые/будущие годы.
5. С главного экрана убраны переключатели количества месяцев.
6. В экранах дат по привычке нет никаких метрик.
7. Более нативный iOS-вид: переходы, нажатия, шит, контекстное меню.

### Вне области
- Напоминания/уведомления, экспорт/импорт, синхронизация, аккаунты.
- Уровни интенсивности, числовой ввод (отметка остаётся бинарной).
- Любые метрики и агрегаты по привычке.

## 2. Экраны и навигация

Навигационный стек, переходы — боковой слайд push/pop (см. §5).

### Роуты (hash)
- `#/` — главный (список привычек).
- `#/h/:id` — экран месяца привычки.
- `#/h/:id/year` — экран года привычки.
- `#/settings` — настройки.

Некорректный `:id` (привычки нет) → редирект на `#/`.

### 2.1 Главный экран `#/`
- Шапка: заголовок `Habits` (крупный, 30/700), справа иконка-шестерёнка → `#/settings`.
- Вертикальный список карточек привычек в порядке `state.habits`.
- **Карточка привычки:**
  - Строка: эмодзи + название (15/600, обрезается многоточием).
  - Полоска из **3 календарных месяцев подряд**: предыдущий, текущий, следующий
    относительно сегодняшней даты. Каждый месяц — компактная сетка 7 столбцов,
    **без строки дней недели**, с подписью названия месяца сверху (у текущего —
    красная). Ведущие пустые ячейки под смещение первого дня (недели с
    понедельника). Размер ячеек подобран так, чтобы 3 месяца + отступы помещались
    в ширину экрана без горизонтального скролла (ориентир: экран 375pt, боковые
    поля 16pt, карточка padding 14pt → на месяц ~99pt → ячейка ~13–14pt; цифры
    ~9px).
  - Состояния дней — как в §3.2, в компактном масштабе.
  - Полоска **только для просмотра**: тап в любом месте области календаря карточки
    → переход на `#/h/:id` (экран месяца), проскролленный к текущему месяцу.
  - **Долгое нажатие** (~450мс) по карточке → контекстное меню (§5.4):
    «Изменить» (открывает шит редактирования) / «Удалить» (нативный `confirm`,
    затем `deleteHabit` + перерисовка).
- Плавающая кнопка **+** (акцент приложения) → шит добавления (§5.3).
- Пустое состояние: короткий текст + кнопка «Добавить привычку».
- На главном **нет**: переключателей диапазона, кнопки «отметить сегодня», метрик.

### 2.2 Экран месяца `#/h/:id`
- Шапка (одна строка, sticky): слева `‹ 2026` (текущий год, в акцентном цвете) —
  тап → `#/h/:id/year`. По центру — эмодзи + название привычки (14/600).
- Строка дней недели `п в с ч п с в` (с понедельника), sticky под шапкой,
  разделительная линия снизу.
- **Непрерывный вертикальный скролл месяцев.** Каждый месяц:
  - крупное название месяца (22/700); у месяца, содержащего сегодня, — красное.
  - сетка 7 столбцов, ведущие пустые ячейки под смещение, ячейки ≥ 44pt по
    меньшей стороне.
- Открывается проскролленным так, чтобы **текущий месяц** был вверху видимой
  области.
- Начальное окно рендера: `[текущий − 12 … текущий + 1]` месяцев. При скролле
  к верхней границе — достроить ещё 12 месяцев назад (лениво, без ограничения).
  Вниз дальше «текущий + 1» не рендерим (будущее не отмечается).
- Тап по дню:
  - будущий день (`date > today`) — ничего (ячейка приглушена, `pointer-events:none`).
  - иначе — тоггл `entries[date]`, `persist()`, точечное обновление классов
    ячейки (без полной перерисовки экрана).
- **Метрик нет.**

### 2.3 Экран года `#/h/:id/year`
- Шапка (sticky): слева `‹ Привычки` — тап → `#/` (главный). По центру —
  название привычки. Отдельно — **прилипающий заголовок текущего по скроллу
  года** (крупная цифра года).
- **Непрерывный вертикальный скролл через годы.** Внутри года — 12 мини-месяцев,
  по 3 в ряд. Мини-месяц: подпись названия (у месяца с сегодня — красная), сетка
  7 столбцов с крошечными ячейками; отмеченные дни — заливка цветом привычки;
  сегодня — красная заливка/цифра.
- Только вертикальный скролл. После декабря идёт январь следующего года; скролл
  вверх открывает прошлые годы. Начальное окно: `[текущий год − 1 … текущий год]`;
  ленивое достраивание в обе стороны при подходе к границам.
- Открывается проскролленным к текущему месяцу текущего года.
- Тап по мини-месяцу → `#/h/:id` (экран месяца), проскролленный к этому месяцу.
- **Метрик нет.**

### 2.4 Настройки `#/settings`
- Без изменений относительно v1: шапка с `‹ Привычки` (назад на `#/`) и
  сегмент «Тема»: Система / Светлая / Тёмная, мгновенно применяется и
  сохраняется в `state.settings.theme`.

### 2.5 Карта переходов
| Откуда | Действие | Куда | Переход |
|---|---|---|---|
| Главный | тап по карточке | Экран месяца (`#/h/:id`) | push (слайд влево) |
| Главный | тап по шестерёнке | Настройки | push |
| Главный | лонг-пресс карточки | контекстное меню (оверлей) | fade + подъём |
| Экран месяца | `‹ 2026` | Экран года (`#/h/:id/year`) | push |
| Экран месяца | системный свайп от левого края / back | Главный | pop (слайд вправо) |
| Экран года | `‹ Привычки` | Главный | pop |
| Экран года | тап по мини-месяцу | Экран месяца (на этом месяце) | push |
| Настройки | `‹ Привычки` | Главный | pop |

Реализация стека: `app.js` хранит текущий и предыдущий hash; при `hashchange`
определяет направление (push, если новый уровень глубже; pop, если мельче) и
проигрывает соответствующую анимацию контейнеров (§5.1).

## 3. Данные и рендер календаря

### 3.1 Модель данных
Без изменений относительно v1. `localStorage`, ключ `habitTracker.v1`:
```js
{
  version: 1,
  settings: { theme: "system" | "light" | "dark" },
  habits: [
    {
      id, name, emoji, accent,       // accent — ключ из ACCENT_KEYS
      createdAt,                      // "YYYY-MM-DD", теперь только метаданные
      archived: false,
      entries: { "2026-09-01": true, ... }
    }
  ]
}
```
- `migrate()` / нормализация записей из v1 сохраняются (см. v1-спеку §3 и
  финальные фиксы: бэд-`accent` → `ACCENT_KEYS[0]`, `entries` не объект → `{}`,
  `createdAt` не `YYYY-MM-DD` → `todayStr()`, не-объекты в `habits` отбрасываются).
- Баннер повреждённых данных (`state._corrupt`) и защита `persist()` — сохраняются.
- **`createdAt` больше не ограничивает отметки.** Любой день `date <= today`
  доступен для тоггла (проставление задним числом разрешено). Дни `date > today`
  не отмечаются.

### 3.2 Состояния дня
Определяется чистой функцией `dayState(dateStr, entries, todayStr)`:
| Состояние | Условие | Вид |
|---|---|---|
| `future` | `dateStr > todayStr` | приглушённая цифра, `pointer-events:none` |
| `marked-today` | `dateStr === todayStr && entries[dateStr]` | кружок цвета привычки + красное кольцо, белая цифра |
| `today` | `dateStr === todayStr` | красная цифра, без заливки |
| `marked` | `entries[dateStr]` | кружок цвета привычки, белая цифра |
| `plain` | иначе | обычная цифра |

Цвет привычки подаётся в CSS как `--habit-accent` (инлайн, из
`ACCENTS[habit.accent][resolvedTheme]`), выставляется на контейнере экрана /
карточки. Красный — токен `--today`.

### 3.3 Построение сетки — `js/calendar.js` (чистый модуль)
- `monthMatrix(year, month)` → `Array<Array<string|null>>` — недели (с
  понедельника) по 7 элементов; `null` для ведущих/замыкающих пустых ячеек;
  иначе `"YYYY-MM-DD"`. `month` 0–11.
- `monthName(month)` → русское название («Январь» … «Декабрь»).
- `weekdayLabels()` → `['п','в','с','ч','п','с','в']`.
- `listMonths(fromYM, toYM)` → массив `{year, month}` включительно, для окна
  рендера (`YM` = `{year, month}`).
- `dayState(dateStr, entries, todayStr)` → одна из строк §3.2.
- `todayYM(todayStr)` → `{year, month}`.
Зависит только от `js/stats.js` (`parseDate`, `formatDate`, `addDays`,
`mondayOf`). Без DOM.

### 3.4 Что удаляется из `js/stats.js`
Убрать (не используются нигде в v2) вместе с их тестами:
`currentStreak`, `longestStreak`, `totalDays`, `completionRate`, `rangeBounds`,

Оставить: `formatDate`, `parseDate`, `todayStr`, `addDays`, `mondayOf`,

### 4.1 `js/ui.js` — чистый слой представления (строки HTML, без событий, без DOM-чтения)
Экспорт:
- `esc(s)` — как в v1.
- `mainHTML({ state, theme })` — шапка + список карточек + FAB. Карточка:
  `data-action="open-habit" data-id`; область календаря = 3 вызова
  `miniMonthHTML`. Инлайн `--habit-accent` на карточке.
- `miniMonthHTML({ ym, habit, todayStr, theme })` — компактный месяц для главной
  (без строки дней недели, с подписью месяца).
- `monthGridHTML({ ym, habit, todayStr })` — полноразмерный месяц для экрана
  месяца (название + сетка; дни: `data-action="toggle-day" data-id data-date`
  для не-`future`).
- `monthViewHTML({ state, id, months, theme })` — шапка (`‹ <year>`,
  название привычки), sticky строка дней недели, поток `monthGridHTML` по
  массиву `months` (`[{year,month}]`).
- `yearBlockHTML({ year, habit, todayStr })` — 12 мини-месяцев года, 3 в ряд
  (`data-action="open-month" data-id data-year data-month`).
- `yearViewHTML({ state, id, years, theme })` — шапка (`‹ Привычки`,
  название), sticky заголовок года, поток `yearBlockHTML` по массиву `years`.
- `sheetHTML({ sheet, state, theme })` — как в v1, с добавлением грабера и
  классов под свайп-закрытие (логика свайпа — в `app.js`).
- `settingsHTML({ state, theme })` — как в v1.
- `contextMenuHTML({ habit })` — оверлей: затемнение с блюром, «карточка-призрак»
  (или просто подсветка), список действий
  `data-action="edit-habit"|"delete-habit" data-id`, `data-action="close-context"`
  на фоне.

Убрать: `heatmapHTML`, `segmentHTML`, `detailHTML`, `RANGES`, `WD` (переехать в
`calendar.js` как `weekdayLabels`).

### 4.2 `js/app.js` — состояние, роутинг, переходы, жесты
- Состояние: `state`, `sheet` (как в v1), плюс `context` (id привычки для
  контекстного меню или `null`), `prevHash` (для направления перехода).
  Убрать `range`.
- Окна рендера:
  - экран месяца: `months` = `listMonths(todayYM − 12мес, todayYM + 1мес)`;
    хранить границы, расширять вверх по обработчику скролла контейнера.
  - экран года: `years` = `[todayYear − 1, todayYear]`; расширять в обе стороны.
  - Расширение окна = пересобрать innerHTML соответствующего контейнера с
    сохранением `scrollTop` (компенсировать сдвиг при добавлении контента сверху).
- `render()` — по `location.hash` выбирает `mainHTML` / `monthViewHTML` /
  `yearViewHTML` / `settingsHTML`; выставляет `#app`. Затем:
  - экран месяца: проскроллить к текущему (или запрошенному) месяцу.
  - экран года: проскроллить к текущему году/месяцу.
  - `#sheet` ← `sheetHTML(...)` или пусто; фокус `#habit-name` при открытии.
  - `#context` ← `contextMenuHTML(...)` или пусто.
- Переходы (§5.1): при `hashchange` сравнить глубину нового и старого hash,
  проиграть слайд-анимацию двух слоёв (уходящий/приходящий) через CSS-классы;
  `prefers-reduced-motion` → простой кросс-фейд.
- Делегированный обработчик `click` по `data-action`:
  `open-habit` (→ `#/h/:id`), `open-year` (→ `#/h/:id/year` — с кнопки `‹ 2026`),
  `open-month` (→ `#/h/:id`, запомнить целевой месяц для скролла),
  `back-main` (→ `#/`), `open-settings`, `toggle-day` (тоггл + точечное
  обновление классов ячейки + `persist`), `add`, `edit-habit`, `pick-accent`,
  `save-habit`, `cancel-sheet`, `set-theme`, `close-context`, `delete-habit`
  (`confirm` → `deleteHabit` → `persist` → закрыть меню → `render`).
- Долгое нажатие: на `pointerdown` по `.card` — таймер ~450мс; если не было
  движения/`pointerup`/скролла — `context = id; render()`. Отмена по `pointermove`
  за порогом, `pointerup`, `scroll`.
- Свайп-закрытие шита: `pointerdown/move/up` по `.sheet` — тянем вниз за
  `translateY`, при > ~30% высоты или быстром флике — `cancel-sheet`.
- Тема: `applyTheme()` / `resolvedTheme()` / `mq` listener — как в v1. Токен
  `--today` в CSS (не зависит от JS).
- `persist()` — как в v1 (no-op при `_corrupt`); `save-habit` чистит `_corrupt`.
- Регистрация service worker — через `js/sw-register.js`, без изменений.

## 5. Нативный iOS-вид (детали)

### 5.1 Переходы экранов
- Два слоя в `#app`-обёртке: уходящий и приходящий.
- push: приходящий `translateX(100%) → 0`; уходящий `0 → translateX(-25%)` +
  затемнение. pop: зеркально.
- Тайминг ~340мс, `cubic-bezier(.32,.72,0,1)` (iOS-подобный).
- `@media (prefers-reduced-motion: reduce)` → без слайда, `opacity` кросс-фейд 120мс.

### 5.2 Нажатия
- `.day:not(.future)`, `.row`, `.btn`, `.seg-item`, кнопки шапки: `:active` →
  `opacity:.55` и/или `transform:scale(.96)`, переход 90мс.
- `-webkit-tap-highlight-color: transparent`.
- Тап-цели: дни в экране месяца ≥ 44pt; кнопки шапки ≥ 44pt. На главной полоске
  дни мельче — она только для просмотра.

### 5.3 Шит добавления/редактирования
- Снизу, `border-radius: 20px 20px 0 0`, грабер (36×5, `--text-tertiary`) по
  центру сверху.
- Появление: `translateY(100%) → 0`, ~300мс ease-out; фон `rgba(0,0,0,.4)` fade.
- Свайп вниз закрывает (порог 30% высоты или флик). Тап по фону закрывает.
- Внутри — как в v1: имя (`#habit-name`, maxlength 40), эмодзи (`#habit-emoji`,
  maxlength 8), ряд из 10 акцент-кружков, «Отмена» / «Сохранить». Сохранение
  живого ввода при `pick-accent` (фикс из v1) сохраняется.

### 5.4 Контекстное меню (лонг-пресс карточки)
- Оверлей `#context`: фон `backdrop-filter: blur(20px)` + `rgba(0,0,0,.25)`.
- Карточка визуально «поднимается»: копия/подсветка с `transform: scale(1.03)` и
  тенью (реализация — либо клон в оверлее, либо `position:relative; z-index`
  на самой карточке поверх затемнения; выбрать проще при реализации).
- Снизу под карточкой — список действий (`.ctx-menu`): «Изменить», «Удалить»
  (красным). Появление: fade + `scale(.9)→1`, ~200мс.
- Закрытие: тап по фону, Esc, выбор действия.
- `prefers-reduced-motion` → без scale, только fade.

### 5.5 Скролл
- Контейнеры месяца/года: `overflow-y:auto; -webkit-overflow-scrolling:touch;
  overscroll-behavior:contain`.

### 6.4 Ручной чек-лист приёмки
1. Главный: у каждой привычки видны ровно 3 месяца (пред/тек/след), без
   горизонтального скролла на 375pt; сегодня — красная цифра; отмеченные дни —
   кружок цвета привычки.
2. Тап по карточке → экран месяца, открыт на текущем месяце, шапка `‹ 2026` +
   название.
3. В экране месяца: скролл вверх подгружает прошлые месяцы; тап по прошлому дню
   ставит/снимает кружок и переживает перезагрузку; тап по будущему дню — ничего.
4. Экран месяца: метрик нет нигде.
5. `‹ 2026` → экран года; непрерывный вертикальный скролл, после декабря —
   январь следующего года, вверх — прошлые годы; заголовок года прилипает.
6. Тап по мини-месяцу в году → экран месяца на этом месяце.
7. `‹ Привычки` с года → главный.
8. Лонг-пресс карточки → меню с блюром; «Изменить» открывает шит с данными;
   «Удалить» (после подтверждения) убирает привычку.
9. Шит: грабер, выезд снизу, свайп вниз закрывает; добавление привычки работает,
   сохранение цвета при вводе имени не теряет имя.
10. Настройки: Система/Светлая/Тёмная применяются мгновенно и переживают
    перезагрузку; `--today` красный в обеих темах.
11. Переходы между экранами — слайд push/pop; при включённом
    «уменьшить движение» — кросс-фейд.
12. Офлайн (домашний экран): приложение открывается, отметки сохраняются;
    после бампа `CACHE` до v2 старый кэш удаляется.
13. Прогон из подкаталога Pages — все ресурсы и SW грузятся (относительные пути).
