# Трекер привычек — дизайн-спека

Дата: 2026-09-02
Статус: утверждено, готово к планированию реализации

## 1. Обзор

Персональное веб-приложение — трекер привычек для iPhone. Публикуется на GitHub
Pages, сохраняется на домашний экран как PWA, работает офлайн. Один пользователь,
без бэкенда.

### Возможности
- Добавлять / изменять / удалять привычки.
- Отмечать день выполненным (бинарно: выполнено / нет).
- Хитмап в стиле GitHub за длинный период.
- Просмотр статистики за диапазон: неделя, месяц, 3 месяца, 6 месяцев, год, всё время.
- Светлая / тёмная тема (по системе + ручной выбор с запоминанием).
- Минималистичный аккуратный дизайн, системный шрифт.

### Решения, принятые на брейншторме
| Вопрос | Решение |
|---|---|
| Хранение данных | Только `localStorage`. Без экспорта/импорта, без синхронизации. |
| Тип отметки | Бинарно. Есть запись на дату = день выполнен. |
| Технологии | Чистый HTML/CSS/JS, ES-модули, без сборки. |
| Офлайн | Полноценный PWA: манифест, иконки, service worker с precache. |
| Тема | По умолчанию системная; ручной выбор Система / Светлая / Тёмная сохраняется. |

### Вне области
- Напоминания / уведомления.
- Уровни интенсивности или числовой ввод.
- Несколько пользователей, аккаунты, облако.
- Экспорт/импорт данных.

## 2. Архитектура

Статические файлы, отдаются как есть с GitHub Pages. Скрипты — ES-модули
(`<script type="module">`), работают по HTTPS с Pages без сборки.

```
index.html
styles.css                 — токены тем + вся вёрстка
js/storage.js              — чтение/запись localStorage, схема, миграции
js/stats.js                — чистые функции статистики (тестируются)
js/heatmap.js              — построение сетки клеток по диапазону
js/ui.js                   — рендер списка, экрана деталей, нижних шитов, настроек
js/app.js                  — точка входа, роутинг по location.hash
manifest.webmanifest
sw.js                      — service worker, precache статики
icons/
  icon-192.png
  icon-512.png
  icon-maskable-512.png
  apple-touch-icon.png     — 180×180
tests/stats.test.js        — node --test
README.md                  — как опубликовать и добавить на домашний экран
```

### Роутинг (hash-based, работает на Pages без конфигурации)
- `#/` — список привычек (главный экран).
- `#/habit/:id` — детали привычки.
- `#/settings` — настройки.

## 3. Модель данных

`localStorage`, ключ `habitTracker.v1`. Одна запись — весь стейт, сериализуется в JSON.

```js
{
  version: 1,
  settings: {
    theme: "system" | "light" | "dark"   // по умолчанию "system"
  },
  habits: [
    {
      id: "h_ab12cd",              // "h_" + 6 символов base36
      name: "Post on Threads",     // 1..40 символов, обязательно
      emoji: "🧵",                  // строка эмодзи или "" — необязательно
      accent: "indigo",            // ключ из палитры акцентов привычек (см. §5.3)
      createdAt: "2026-01-15",     // YYYY-MM-DD, локальная дата
      archived: false,             // зарезервировано; в UI пока не используется
      entries: {                   // множество выполненных дат
        "2026-09-01": true,
        "2026-09-02": true
      }
    }
  ]
}
```

### Правила
- Дата — всегда локальная (`YYYY-MM-DD`), считается из `new Date()` пользователя.
- «Отметить сегодня» — тумблер: добавляет или удаляет ключ `entries[today]`.
- В деталях можно тапнуть любую клетку хитмапа, чтобы переключить любой день
  (не только сегодня).
- Удаление привычки — с подтверждением (нативный `confirm` или кастомный шит),
  восстановления нет.
- При старте: если ключа нет — создаётся пустой стейт версии 1. Если
  `version` меньше текущей — прогоняются миграции по возрастанию.
- Любая ошибка `JSON.parse` → стейт считается пустым (данные не трогаем,
  показываем баннер «не удалось прочитать сохранённые данные»).

## 4. Экраны и поведение

### 4.1 Список привычек `#/`
- Заголовок `Habits`.
- Сегмент-переключатель диапазона: **Год · 6 мес · 3 мес · Месяц · Неделя**
  (один на весь экран, применяется ко всем карточкам). Выбор хранится в памяти
  сессии, по умолчанию «Год».
- Карточка привычки:
  - эмодзи + название;
  - справа мета: `🔥 <текущий стрик> · <всего дней>d`;
  - хитмап за выбранный диапазон (§4.4);
  - кнопка «Отметить сегодня» — заполнена акцентом привычки, если сегодня
    отмечено; контурная, если нет.
  - тап по телу карточки (не по кнопке) → `#/habit/:id`.
- Плавающая кнопка **+** (FAB, акцент приложения) → шит добавления.
- Пустое состояние: короткий текст + кнопка «Добавить привычку».

### 4.2 Детали привычки `#/habit/:id`
- Шапка: кнопка «назад», эмодзи + название.
- Крупный хитмап + тот же сегмент-переключатель диапазона.
- Блок статистики (4 значения, `tabular-nums`):
  - Текущий стрик (дней подряд до сегодня; если сегодня не отмечено, но вчера —
    стрик продолжается и равен серии по вчера включительно);
  - Лучший стрик;
  - Всего дней;
  - Выполнено за диапазон, `% = отмечено / всего дней в диапазоне`.
- Клетки хитмапа тапабельны — переключают день.
- Кнопки: «Изменить» (шит), «Удалить» (подтверждение, затем → `#/`).

### 4.3 Добавить / изменить (нижний шит)
- Поле названия (автофокус, до 40 символов).
- Выбор эмодзи: поле, открывающее нативную клавиатуру эмодзи; можно оставить пустым.
- Выбор акцента: ряд из 10 кружков (§5.3), один выбран.
- Кнопки «Сохранить» / «Отмена». Для новой привычки по умолчанию берётся
  следующий неиспользованный акцент по порядку.

### 4.4 Хитмап — единый режим отрисовки
Сетка «столбцы-недели × 7 строк-дней» (Пн…Вс сверху вниз), как на GitHub.
- Заполненная клетка = акцент привычки; пустая = `--cell-empty`;
  клетка сегодняшнего дня = кольцо `box-shadow: 0 0 0 1.5px <accent>`.
- Радиус клетки 2px, размер 9–11px (адаптивно по ширине), gap 3px.
- Подписи месяцев над столбцами (сокр. локали), там где начинается месяц.
- Число столбцов по диапазону:
  | Диапазон | Что показываем |
  |---|---|
  | Неделя | последние 7 дней одним рядом, клетки крупнее |
  | Месяц | ~5 столбцов (последние ~35 дней, выровнено по неделям) |
  | 3 месяца | ~14 столбцов |
  | 6 месяцев | ~27 столбцов |
  | Год | ~53 столбца |
  | (на экране деталей) Всё время | от `createdAt`, горизонтальный скролл |
- Диапазон всегда заканчивается текущей неделей (последний столбец содержит сегодня).
- Дни до `createdAt` и будущие дни в текущей неделе рендерятся как пустые
  неактивные (чуть прозрачнее, не тапабельны).

### 4.5 Настройки `#/settings`
- Сегмент «Тема»: Система / Светлая / Тёмная. Применяется мгновенно, пишется в
  `settings.theme`.

## 5. Визуальный дизайн

### 5.1 Тема — механика
- Токены объявлены на `:root` (светлая палитра как база).
- `@media (prefers-color-scheme: dark)` под `:root:not([data-theme="light"])` —
  тёмные значения.
- `:root[data-theme="dark"]` — тёмные значения (ручной выбор перекрывает систему
  в обе стороны).
- `js/app.js` при старте ставит `data-theme` из `settings.theme`
  (`"system"` → атрибут не ставится).
- `<meta name="theme-color">` — два варианта через `media`, либо обновляется из JS
  при смене темы: светлая `#F6F7F9`, тёмная `#0A0C0F`.
- `body` всегда красит фон явным токеном (`--bg`).

### 5.4 Типографика
- Стек: `-apple-system, "SF Pro Text", "Inter", system-ui, sans-serif`.
  Ничего не бандлим — на iPhone это SF Pro.
- Заголовок экрана: `20px / 650 / -0.02em`.
- Название привычки: `14px / 600 / -0.01em`.
- Кнопки, пилюли: `12px / 600`.
- Мета, подписи: `11–12px / 550`, цвет `--text-secondary`.
- Микроподписи (uppercase-лейблы): `10px / 600 / 0.06em / uppercase`, `--text-tertiary`.
- Числа (стрик, дни, %): `font-variant-numeric: tabular-nums`.
- `-webkit-font-smoothing: antialiased` на `body`.
- Базовый размер body `14px`,高 line-height `1.4`.

### 5.5 Прочее
- Тап-цели ≥ 40px по меньшей стороне (клетки хитмапа — исключение, работают по
  всей строке/увеличенной зоне на экране деталей).
- `env(safe-area-inset-*)` — отступы под вырез и home-indicator.
- `-webkit-tap-highlight-color: transparent`, свои `:active`-состояния.
- Анимации: только `opacity`/`transform`, 120–160ms ease-out; уважать
  `prefers-reduced-motion`.

## 7. Логика статистики (`js/stats.js`)

Чистые функции, без обращения к DOM и `localStorage`. Вход — объект `entries`
и/или список дат, выход — числа/массивы.

- `todayStr()` → локальная `YYYY-MM-DD`.
- `parseDate(str)` / `formatDate(date)` — без UTC-сдвигов (конструктор по
  компонентам).
- `enumerateDays(fromStr, toStr)` → массив дат включительно.
- `currentStreak(entries, todayStr)` → число. Считает подряд идущие
  выполненные дни, заканчивая сегодня; если сегодня не отмечено — считает по
  вчера включительно; 0, если и вчера не отмечено.
- `longestStreak(entries)` → максимальная серия за всю историю.
- `totalDays(entries)` → количество ключей.
- `completionRate(entries, fromStr, toStr)` → `{ done, total, pct }`,
  `pct` округляется до целого.
- `rangeBounds(rangeKey, todayStr, createdAtStr)` → `{ fromStr, toStr }` для
  ключей `week | month | q | half | year | all`, выровнено по неделям для
  сетки (кроме `week`).

### Тесты `tests/stats.test.js` (`node --test`)
- пустые `entries`: все функции возвращают нули, не бросают;
- `currentStreak`: отмечено сегодня; не сегодня, но вчера; разрыв позавчера;
  один день;
- `longestStreak`: серия в середине истории; вся история подряд; одиночные дни;
- переход через месяц и через год (31.12 → 01.01);
- високосный февраль (29.02.2028) в `enumerateDays`;
- `completionRate`: диапазон длиннее истории; диапазон в один день;
- `rangeBounds`: `all` при отсутствии записей = `createdAt..today`;
  граница недели не заходит в будущее.

## 8. Ручной чек-лист приёмки

1. Добавить привычку → появляется в списке с выбранным эмодзи и акцентом.
2. «Отметить сегодня» → клетка сегодня заполняется; повторный тап снимает.
3. Перезагрузка страницы → данные на месте.
4. Открыть детали → 4 метрики считаются верно на подготовленных данных.
5. Тап по прошлой клетке в деталях → день переключается, метрики пересчитываются.
6. Переключить диапазон → хитмап и `%` меняются на всех экранах.
7. Изменить привычку (имя/эмодзи/акцент) → отражается везде.
8. Удалить привычку → подтверждение → исчезает, возврат на список.
9. Настройки: Светлая / Тёмная / Система → тема и `theme-color` меняются
   мгновенно, выбор переживает перезагрузку.
10. Тёмная тема соответствует токенам §5.2 (глубокий сине-чёрный фон, границы
    вместо теней).
11. Офлайн (Airplane Mode) → запуск с домашнего экрана открывает приложение с
    данными.
12. Добавлено на домашний экран → иконка корректная, запуск в полноэкранном
    `standalone`, отступы под вырез/home-indicator соблюдены.
13. Прогон из подкаталога Pages (`/habit-tracker/`) → все ресурсы и SW
    грузятся (относительные пути).

## 9. Открытые мелочи (решить при реализации, не блокеры)
- Подтверждение удаления: нативный `confirm` или кастомный шит — на усмотрение,
  приоритет аккуратности.
- Точная ширина клетки хитмапа под 375pt экран — подобрать так, чтобы год
  влезал без горизонтального скролла на главном экране.
- Иконки PWA: сгенерировать из простого знака (напр. точка-сетка на фоне
  `--accent`).
